and close. Store is scoped to active company/authenticated user and retains explicit
branch identity/filtering. Maximum100 records per scope and100 lines per draft.
It stores only stable references, expected versions, exact quantity/unit strings,
unit choices, conflict state and pending save identity. Whitelist excludes tokens,
names/contacts, prices, payments, reservations and approvals.

Origin-wide Web Locks serialize storage writes/deletes with expected local revision
checks. Another tab cannot silently overwrite/delete a newer copy. Unsupported
locking or quota failures surface explicitly. Exact request is persisted BEFORE
network submission; failed persistence blocks network save. Confirmed server save
removes only the expected recovery revision. No automatic replay or offline posting.
Local data is untrusted; existing backend authorization/version/source validation
and atomic receipt still govern every save and retry. This is browser storage,
not encrypted shared-device storage or a server backup. Clearing site data loses it.
Recovery metadata is not authoritative stock availability or current pricing.
