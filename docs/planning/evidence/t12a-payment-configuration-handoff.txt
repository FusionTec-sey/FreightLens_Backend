Backend API contract (all private/no-store; JWT and active org required):
- GET /sales/payment-configuration/branches?page=&limit= returns paginated
  active and inactive branch options for financial configuration only.
- GET /sales/payment-configuration/methods?page=&limit= returns latest revisions.
- PUT /sales/payment-configuration/methods/{method_key} takes operation_key,
  expected_version, immutable code, config {label, kind, is_enabled}, reason.
- GET /sales/payment-configuration/receiving-accounts?page=&limit=&branch_id=
  returns latest mapping revisions; foreign branch filter returns 404.
- PUT /sales/payment-configuration/receiving-accounts/{mapping_key} takes
  operation_key, expected_version, immutable branch_id and method_key,
  config {account_ref, label, is_enabled}, reason.
- GET /sales/payment-configuration/receiving-account-lookup?branch_id=&method_key=
  returns READY plus exact mapping key/version/reference or BLOCKED with
  BRANCH_DISABLED, METHOD_DISABLED, MAPPING_MISSING, MAPPING_DISABLED. Foreign
  branch/method returns 404. T13 must call this from its own trusted transaction
  and revalidate under its posting authority; this slice does not wire it.
