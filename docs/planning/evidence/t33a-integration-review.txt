2. countsApi source choices use /sales/draft-sources/branches and /products.
   Those endpoints require SALES/customer personal-data access; branches returns
   active STORE only. Warehouse count planning must use Inventory-authorised,
   same-company selectors rather than require sales access or exclude warehouses.
3. BlindCountSheet leaves quantity/unit inputs and Back enabled on uncertain save.
   pending preserves old request but visible edits can diverge; success clears all
   values after retry. Freeze pending intent, guard discard/navigation, and retain
   the saved receipt separately from refresh failure before integration acceptance.
4. saveCounted clears inputs before a follow-up sheet refresh, then reports refresh
   failure as an uncertain save. Separate committed receipt and failed reload;
   never invite a new save for an already confirmed effect.
