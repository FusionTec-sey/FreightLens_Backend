Scope
- Versioned, immutable and tenant-owned logical account configuration for one exact
  branch and role. No mapping row or real account reference is seeded.
- Supported pilot roles: SALES_REVENUE, OUTPUT_TAX_PAYABLE,
  CUSTOMER_CREDIT_LIABILITY, COST_OF_GOODS_SOLD, INVENTORY_ASSET,
  CASH_OVER_SHORT and CASH_DEPOSIT_CLEARING.
- T12 remains authoritative for exact payment-method receiving-account references.
- Pure immutable SCR journal composition only. No journal persistence, till close,
  period fence, file export or financial activation is included.

Safety contract
- SALES subscription, View_Financials/Manage_Financials and the FINANCIAL field
  class are enforced at HTTP and service retry boundaries.
- Stable operation IDs, expected versions, active-branch checks and exact tenant
  ownership are required. Reads are private/no-store and server-paginated.
- Lookup never chooses another branch. Missing, disabled and disabled-branch states
  are explicit and callers may lock an exact mapping key/version before composition.
- Branch, mapping-key and target locks serialize competing identities/targets.
- Database triggers make configuration history append-only and constraints reject
  missing actors or soft-deleted/deleted immutable rows.
- Journal values must be exact positive Decimal SCR cents; binary floats,
  unsupported roles, invalid account references and unbalanced journals fail.
