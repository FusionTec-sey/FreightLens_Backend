New Execute_OtherStoreFulfilment permission, no automatic role grants.
GET /inventory/other-store-fulfilment-cases/{key}/execution-context returns only
case/target branch/settings version after runtime ownership check.
POST .../{key}/execute takes operation UUID and branch_version only. Stock target,
source, quantity, units and follow-up are server-derived from the reviewed case.
require_stock_business_date reuses versioned branch calendars and date overrides;
missing, stale or closed target calendar blocks. No client-supplied dates/node.
reserve_stock adds optional checked-settings version to its request fingerprint,
retaining existing approval/source/stock/version/authority/quantity protections.
Hold UUID is deterministic per case; no duplicate ledger or source record.

Sales drafts -> Other-store reviews -> approved case: shared confirmation UI
loads target context and offers explicit execution to separately permitted users.
Missing runtime disables action; same operation retries remain fixed; result stays
visible until dismissed. Stock remains at the selected location; no goods transfer,
physical collection, payment or customer confirmation is claimed.
